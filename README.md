# CSS Flexbox 

## Project Description

This project demonstrates the use of CSS Flexbox to position six boxes in all nine positions of a full-screen container.

The six boxes move through:

1. Top Left
2. Top Center
3. Top Right
4. Middle Left
5. Center
6. Middle Right
7. Bottom Left
8. Bottom Center
9. Bottom Right

The project uses HTML and CSS only. No JavaScript is used.

---

## Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS `@keyframes` animation

---
